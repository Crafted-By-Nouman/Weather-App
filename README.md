# 🌦️ Climatrix - Next-Gen Weather Intelligence

**Climatrix** is a futuristic, responsive, and visually stunning weather forecast website built using pure **HTML, CSS, and JavaScript**. It provides real-time weather data with dynamic UI animations and intelligent features, delivering a smooth user experience across all devices.

## 🚀 Live Demo

👉 [Click Here to View Live](https://crafted-by-nouman.github.io/Weather-App/)

--- 

## ✨ Features

- 🌍 Real-time weather using **OpenWeatherMap API**
- 📍 Auto-detect current location via Geolocation API
- 🔍 Search any city’s weather forecast
- 🌡️ Display: temperature, feels-like, humidity, pressure, wind, visibility
- ☀️ Dynamic weather icons and background changes
- 📆 7-day forecast with responsive weather cards
- ⏰ Hourly forecast slider
- 🌙 Sunrise, sunset & moon phase
- ⚠️ Weather alerts and warnings
- 🔄 Toggle between °C / °F
- 💨 Air Quality Index & UV Index display
- 🌓 Light/Dark mode toggle
- ❤️ Save favorite cities (localStorage)
- 🎤 Voice input (speech-to-text search)
- 🔊 Text-to-speech weather summary
- 📱 Fully responsive on all screen sizes
- 🌐 SEO-optimized with semantic HTML & fast performance

---

## 🧠 Technologies Used

- HTML5 (semantic & SEO friendly)
- CSS3 (Flexbox, Grid, Animations, Glassmorphism)
- JavaScript (ES6+, Geolocation, Fetch API, DOM)
- OpenWeatherMap API
- Pure Vanilla Code — no frameworks!
